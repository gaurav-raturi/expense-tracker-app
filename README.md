# Expense Tracker

A modern and responsive Expense Tracker built with **React.js** that helps users manage their income and expenses with a clean and user-friendly interface.

## Features

- ➕ Add new income and expense transactions
- 🗑️ Delete transactions
- 💵 Track total balance
- 📈 View income and expense summaries
- 📱 Fully responsive design

## Tech Stack

- React.js
- JavaScript
- Vite
- CSS / Tailwind CSS

## Installation

bash
git clone https://github.com/gaurav-raturi/expense-tracker.git
cd expense-tracker
npm install
npm run dev
